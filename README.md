# 星座の家

部屋を円の星として置き、つながりを線で描くと、言葉と簡易図面がついてくる設計スケッチ。

## 動かし方

```bash
cd constellation-house
npm install
npm run dev
```

ブラウザで表示された住所を開く。

## 使い方

1. 「星を置く」を押し、敷地の中をクリックして部屋を足す
2. 星をドラッグして動かす。端の点をドラッグすると広さが変わる
3. 星を選び、部門（色）を割り当てる
4. 「行き来」または「見える」を押し、星を2つクリックして線を引く
5. 右の言葉は、星座に合わせて書き換わる
6. 「図面化」を押すと、床矩形→廊下帯→部門塊→要求室の順で平面化します
7. そのあと星を動かすと、図面は古くなる。もう一度「図面化」する

星を選ぶと、右の欄で名前と広さを変えられる。Delete キーで、選んでいる星や線を消せる。
